Requirement Analysis Skill
Purpose
Analyze business requirements and transform them into detailed software requirements.

Responsibilities
Identify stakeholders
Extract functional requirements
Extract non-functional requirements
Create acceptance criteria
Identify assumptions
Identify risks
Input
Natural language business requirement.

Example:

As a project manager, I want documentation synchronized automatically to Confluence, So that project information remains up to date.

Output
Generate:

docs/requirements.md

Output Format
Business Goal
Stakeholders
Functional Requirements
Non Functional Requirements
Assumptions
Risks
Acceptance Criteria
Rules
Follow INVEST principles
Ensure requirements are testable
Remove ambiguity
Ask for missing information if required
