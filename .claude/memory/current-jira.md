## Update Rules

- Resolve the active issue through Jira MCP when available before each workflow. Verify the issue key and active issue identity.
- Refresh this file only when the active Jira issue changes or verified active-issue details change. Keep exactly one issue here; replace the prior active issue rather than retaining an issue history.
- Store only a concise pointer and summary. Full requirements, acceptance criteria, comments, approvals, and execution evidence belong in the Jira-scoped artifacts and `workflow/workflow-state.json` as appropriate.
- Jira and approved Jira-scoped artifacts outrank this cache. A value here is never proof of approval or current workflow status.
- If Jira cannot be reached, keep unknown fields as `Not Found`; do not infer them from an old issue or a previous session.
