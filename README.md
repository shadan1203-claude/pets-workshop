# Pets workshop

This repository contains the pets-workshop project: a website for a fictional dog shelter, with a [Flask](https://flask.palletsprojects.com/en/stable/) backend using [SQLAlchemy](https://www.sqlalchemy.org/) and an [Astro](https://astro.build/) frontend using [Tailwind CSS](https://tailwindcss.com/).

## Development workflow

Delivery follows a Jira-scoped, approval-gated SDLC driven by Claude Code. See [.claude/CLAUDE.md](./.claude/CLAUDE.md) for the phases, commands, and standards.
